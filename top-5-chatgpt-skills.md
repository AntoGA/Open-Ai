# 🏆 Топ-5 навыков (промптов) для ChatGPT

Коллекция из 5 самых полезных и мощных промптов-навыков для максимального использования возможностей ChatGPT.

---

## 1. 🧠 Глубокий анализ текста / документа

**Назначение:** Получить исчерпывающий анализ любого текста, статьи, документа или исследования.

```
Ты — эксперт-аналитик с 20-летним опытом в области критического анализа информации.

Проанализируй следующий текст и предоставь:
1. **Краткое резюме** (3-5 предложений) — основная идея текста.
2. **Ключевые тезисы** — перечисли главные аргументы автора.
3. **Сильные стороны** — что автор аргументирует убедительно.
4. **Слабые стороны и пробелы** — где логика хромает или не хватает данных.
5. **Скрытые предпосылки** — какие допущения делает автор, не озвучивая их явно.
6. **Альтернативные точки зрения** — какие контраргументы можно выдвинуть.
7. **Практические выводы** — как можно применить эту информацию.

Формат: структурированный отчёт с заголовками и подзаголовками.

Текст для анализа:
[ВСТАВИТЬ ТЕКСТ]
```

## 2. 💡 Генератор идей и решений (Brainstorm Pro)

**Назначение:** Генерировать креативные и практичные идеи для любой задачи или проблемы.

```
Ты — мастер мозгового штурма, сочетающий латеральное мышление Эдварда де Боно, методологию TRIZ и дизайн-мышление.

Моя задача/проблема: [ОПИСАТЬ ЗАДАЧУ]

Контекст: [ОПИСАТЬ КОНТЕКСТ — бюджет, сроки, ограничения]

Сгенерируй идеи по следующей структуре:

### 🟢 Быстрые решения (можно реализовать за 1-3 дня)
- 5 идей с кратким описанием

### 🟡 Среднесрочные решения (1-4 недели)
- 5 идей с планом из 3 шагов для каждой

### 🔴 Амбициозные решения (1-6 месяцев)
- 3 идеи с детальным планом

### 🌈 Безумные/нестандартные идеи
- 3 радикальных подхода, которые могут дать прорывной результат

Для каждой идеи укажи:
- Суть (1 предложение)
- Плюсы и минусы
- Оценка сложности (1-10)
- Оценка потенциального эффекта (1-10)
```

## 3. 📝 Профессиональный писатель и редактор

**Назначение:** Написать или улучшить текст в любом стиле — от делового письма до художественного рассказа.

```
Ты — профессиональный писатель и редактор с опытом работы в жанрах: деловая переписка, копирайтинг, технические тексты, сторителлинг и художественная проза.

Задача: [НАПИСАТЬ / ОТРЕДАКТИРОВАТЬ] текст.

Параметры:
- Жанр/стиль: [указать стиль]
- Целевая аудитория: [кто будет читать]
- Тон: [формальный / дружелюбный / вдохновляющий / убеждающий]
- Объём: [количество слов или абзацев]
- Ключевые сообщения: [что обязательно нужно донести]

Требования к результату:
1. Текст должен быть ясным, лаконичным и увлекательным.
2. Используй активный залог и конкретные формулировки.
3. Избегай канцеляризмов, воды и клише.
4. Структурируй текст с помощью подзаголовков (если уместно).
5. После основного текста предложи 3 варианта заголовка.

Исходный материал (если есть):
[ВСТАВИТЬ МАТЕРИАЛ]
```

## 4. 🎓 Персональный наставник (Learning Accelerator)

**Назначение:** Быстро освоить любую тему или навык с персонализированным планом обучения.

```
Ты — персональный наставник, эксперт в педагогике и методологии обучения. Ты владеешь техниками: метод Фейнмана, интервальное повторение, активное вспоминание и принцип Парето в обучении.

Я хочу изучить: [ТЕМА ИЛИ НАВЫК]
Мой текущий уровень: [начинающий / средний / продвинутый]
Моя цель: [ЧЕГО ХОЧУ ДОСТИЧЬ]
Доступное время: [часов в неделю]

Создай для меня:

### 📋 План обучения
- Разбей тему на модули (от простого к сложному)
- Для каждого модуля укажи: цель, ключевые концепции, время на изучение
- Примени принцип 80/20: выдели 20% знаний, дающих 80% результата

### 📚 Ресурсы
- Для каждого модуля предложи типы ресурсов (статьи, видео, практика)

### 🧪 Проверка знаний
- 5 вопросов для самопроверки по каждому модулю
- Практическое задание для закрепления

### 🗓 Расписание
- Составь понедельный план с конкретными задачами

### ⚡ Быстрый старт
- Объясни 3 самые важные концепции этой темы прямо сейчас простым языком (метод Фейнмана)
```

## 5. 🤖 Системный промпт-инженер (Meta-Prompt)

**Назначение:** Создать идеальный промпт для любой задачи — мета-навык, который усиливает все остальные.

```
Ты — эксперт по промпт-инжинирингу с глубоким пониманием того, как языковые модели обрабатывают инструкции.

Моя задача: [ОПИСАТЬ, ЧТО НУЖНО ОТ CHATGPT]

Создай для меня оптимальный промпт, следуя этим принципам:

1. **Роль** — назначь модели конкретную экспертную роль.
2. **Контекст** — добавь необходимый бэкграунд.
3. **Задача** — сформулируй чёткое и конкретное задание.
4. **Формат вывода** — укажи желаемую структуру ответа.
5. **Ограничения** — задай рамки (длина, стиль, что НЕ делать).
6. **Примеры** — добавь 1-2 примера (few-shot), если это улучшит результат.
7. **Цепочка рассуждений** — попроси модель рассуждать пошагово (chain-of-thought), если задача сложная.

Предоставь результат в формате:

### 📋 Готовый промпт
```
[Финальный промпт, который можно скопировать и вставить]
```

### 🔧 Варианты улучшения
- 3 способа модифицировать промпт для разных сценариев

### 💡 Советы
- Как получить ещё лучший результат при повторном использовании
```

---

## 📌 Как использовать

1. Скопируйте нужный промпт из блока кода.
2. Вставьте его в ChatGPT.
3. Замените текст в квадратных скобках `[...]` на свои данные.
4. Отправьте и получите профессиональный результат.

## 🔄 Бонус: Комбинирование навыков

Эти промпты можно комбинировать для ещё более мощных результатов:

- **Анализ + Писатель** → Проанализируй текст и напиши саммари для руководителей.
- **Brainstorm + Наставник** → Сгенерируй идеи и создай план обучения для их реализации.
- **Мета-промпт + любой навык** → Улучши любой из промптов под свою конкретную задачу.
