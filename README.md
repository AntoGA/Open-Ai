## 🏆 Топ-5 навыков для ChatGPT

1. **🧠 Глубокий анализ текста** — исчерпывающий анализ любого документа с выявлением скрытых предпосылок и альтернативных точек зрения.
2. **💡 Генератор идей (Brainstorm Pro)** — креативный мозговой штурм с использованием TRIZ, дизайн-мышления и латерального мышления.
3. **📝 Профессиональный писатель** — написание и редактирование текстов в любом стиле: от делового до художественного.
4. **🎓 Персональный наставник** — ускоренное освоение любой темы с персонализированным планом обучения.
5. **🤖 Промпт-инженер (Meta-Prompt)** — создание идеальных промптов для любых задач.

## 🐋 Топ-7 навыков для DeepSeek

1. **💻 Эксперт-программист (Code Master)** — написание, рефакторинг и отладка кода с детальными пояснениями и тестами.
2. **🧮 Математический решатель (Math Solver)** — пошаговое решение сложных задач с проверкой и связанными темами.
3. **🔬 Глубокий рассуждатель (Deep Reasoner)** — решение логических и аналитических задач с chain-of-thought.
4. **📊 Аналитик данных (Data Analyst)** — анализ данных, визуализация и извлечение инсайтов с кодом на Python.
5. **📖 Технический писатель (Tech Writer)** — создание README, API-документации и гайдов для разработчиков.
6. **🌐 Мультиязычный переводчик (Polyglot)** — профессиональный перевод с учётом контекста и культурных особенностей.
7. **🏗️ Архитектор решений (Solution Architect)** — проектирование высоконагруженных систем и микросервисной архитектуры.

## 🚀 Быстрый старт

1. Откройте нужный файл с навыками
2. Скопируйте промпт
3. Вставьте в ChatGPT или DeepSeek и замените `[...]` на свои данные
4. Получите профессиональный результат!
