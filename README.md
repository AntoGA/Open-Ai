## 🏆 Топ-5 навыков для ChatGPT

1. **🧠 Глубокий анализ текста** — исчерпывающий анализ любого документа с выявлением скрытых предпосылок и альтернативных точек зрения.
2. **💡 Генератор идей (Brainstorm Pro)** — креативный мозговой штурм с использованием TRIZ, дизайн-мышления и латерального мышления.
3. **📝 Профессиональный писатель** — написание и редактирование текстов в любом стиле: от делового до художественного.
4. **🎓 Персональный наставник** — ускоренное освоение любой темы с персонализированным планом обучения.
5. **🤖 Промпт-инженер (Meta-Prompt)** — создание идеальных промптов для любых задач.

## 🚀 Быстрый старт

1. Откройте файл [top-5-chatgpt-skills.md](top-5-chatgpt-skills.md)
2. Скопируйте нужный промпт
3. Вставьте в ChatGPT и замените `[...]` на свои данные
4. Получите профессиональный результат!
